# Changelog

What's new in Chitchat plugins.

## 1.0 (November 2026)

The first version of plugins.

- **Plugins tab** in Server settings: browse, add, configure, switch off and remove plugins.
- **Bots** show up as members with a BOT badge.
- **Slash commands** with a `/` list in the composer, option hints, checking before sending, private (ephemeral) replies, and "thinking…" for bots that answer later.
- **The Chef**: "Yes Chef.", plus `/chef special`, `/chef rate`, `/chef menu` and `/chef 86`.
- **Automod**: blocked words (with wildcards and sneaky-spelling detection), invite and link filters, mention limits, shouting, bursts, repeats, automatic timeouts, exempt roles and rooms, a "Try a message" preview, and audit log entries.
- **Custom commands**: make your own slash commands without code, with variables, random picks, embeds, role limits and private replies.
- **External bots**: a setup wizard, signed webhooks for events and slash commands, a test ping, the Bot API (messages, embeds, reactions, interaction replies, roles, commands), rate limits, and automatic switch-off after repeated failures.
- **These docs**, at `#/docs`.
